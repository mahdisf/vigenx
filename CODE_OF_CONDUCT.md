# Code of Conduct

ViGenX contributors must keep project spaces technical, factual, and safe for
participation.

Unacceptable conduct includes harassment, threats, discrimination, sexualized
content, publishing private information, deliberate disruption, and repeated
personal attacks. Technical criticism is allowed; abuse of a person is not.

Maintainers may edit or remove content, close threads, reject contributions, or
temporarily or permanently restrict participation when this policy is violated.
Enforcement decisions should be proportional, documented privately, and avoid
exposing reporters or affected people.

Report conduct problems privately to the repository owner through the contact
method on [mahdisf's GitHub profile](https://github.com/mahdisf). Do not post
sensitive reports in a public issue.
