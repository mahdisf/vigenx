# ViGenX example block

This deliberately small external package proves the `vigenx.blocks` discovery
contract without modifying ViGenX core.

```powershell
python -m pip install -e examples/block_plugin
python -m vigenx doctor
```

Restart the editor after installation. See
[`docs/BLOCK_AUTHORING.md`](../../docs/BLOCK_AUTHORING.md) for the full contract.
